# 3D Rotating Image Carousel

An interactive 3D rotating image carousel built using **HTML, CSS, and JavaScript**.

## ✨ Features
- 3D circular image layout using CSS transforms
- Auto-rotation with adjustable speed
- Mouse / touch drag rotation
- Scroll wheel zoom (radius control)
- Background music support
- Supports images and videos

## 🛠️ Technologies Used
- HTML5
- CSS3 (3D Transforms & Animations)
- Vanilla JavaScript
